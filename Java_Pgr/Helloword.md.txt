## 1️⃣ Java Program

### 📝 Question

Write a Java program to print:

> **Love you Java..............!**

### 💡 Approach

Use Java's `System.out.println()` method to print the required message.

### 💻 Solution

```java
public class JavaPgr { 
 
    public static void main(String[] args) { 
       System.out.println("Love you Java..............!"); 
      
    } 
}
```

### ✅ Output

```text
Love you Java..............!
```
